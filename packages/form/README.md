# @likex/form

フォームの作成・回答を行うReactコンポーネント。JSON定義、条件付き表示、入力検証、保存・送信の注入、画面なしの操作APIを提供します。

- [導入](src/docs/getting-started.md)
- [回答と送信](src/docs/answers.md)
- [操作API](src/docs/commands.md)
- [保存と編集許可](src/docs/lifecycle.md)

UIは `@likex/form`、画面なしの操作は `@likex/form/model`、CSSは `@likex/form/styles.css`。ソース＋coreのコピー導入にも対応します。MIT。
