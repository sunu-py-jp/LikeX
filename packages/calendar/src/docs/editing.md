# 表示・日時・予定編集

月表示は曜日に合わせて前後月の日を補います。週・日表示は終日の領域と00:00〜24:00の時間グリッドを持ち、時刻が重なる予定は横に並べます。週・日表示へ切り替えた直後は7時を表示領域の先頭に置きます。0〜6時は上へのスクロールで表示でき、予定の更新だけではスクロール位置を戻しません。「前へ」「次へ」「今日」、月・週・日スイッチで移動します。`weekStartsOn` は月曜の1（既定）か日曜の0です。

「予定を作成」、日付の余白・`+`、時間枠のクリックで小さなクイック入力を開きます。タイトル・終日・開始と終了を設定して、その場で保存できます。「詳細設定」を押すと入力内容を保ったまま大きなダイアログへ切り替わり、場所・説明・色も設定できます。予定のクリックもクイック編集、右クリックの「詳細を開く」は詳細ダイアログを直接開きます。クイック入力は外側クリックまたはEscapeで閉じ、保存前にはモデルを変更しません。マウスのドラッグで別の日・時間枠へ移動します。タッチ操作やキーボード操作ではダイアログの日付・時刻入力から同じ変更を行えます。

## 保存される日時

| 種類 | start / end | 意味 |
| --- | --- | --- |
| 終日 `allDay: true` | `2026-09-22` / `2026-09-24` | 22・23日の2日間。終了日は含まない |
| 時刻指定 `allDay: false` | `2026-09-22T09:00:00+09:00` / `2026-09-22T10:00:00+09:00` | Zまたは明示的なオフセットが必須 |

`calendar.timeZone` はIANAタイムゾーンです。表示・入力はこのゾーンを使い、ゾーン変更だけでは保存済み予定の瞬間を変えません。終日予定は時差で日付がずれません。日をまたぐ予定は各日に表示します。

夏時間開始で存在しないローカル時刻は拒否します。夏時間終了で重複する時刻を入力した場合は、先に起こる瞬間を使います。APIでは明示的なオフセットでどちらも指定できます。ドラッグは時刻指定予定の経過時間、終日予定の日数を保ちます。夏時間終了で同じ時間帯が繰り返される日もUIは24時間の壁時計グリッドです。繰り返し時間の精密な表示には明示的なオフセットをモデルで確認してください。

`onVisibleRangeChange(range)` は表示期間変更時、`onEventClick(event)` は詳細を開いたときに呼ばれます。範囲は `{ start, end, view, timeZone }` で、endは排他的な日付です。日付変更は保存対象を変更せずUndo履歴にも入りません。

繰り返し予定、参加者、招待、通知配信、ICS入出力、CalDAV・外部サービス同期は現時点では未対応です。

## 予定のドラッグ移動

予定をドラッグすると、小さな半透明プレビューと移動先のハイライトを表示します。月表示では日付、週・日表示では終日欄または30分単位の時刻を示します。予定が重なった場所でも、ポインターの位置から移動先の時刻を求めます。表示領域の端や外側では、その方向へ自動スクロールします。

Escape、領域外へのドロップ、表示期間の変更、編集中のデータ変更、読み取り専用への切り替えでドラッグを中止します。別のカレンダーや外部ページから渡されたドラッグデータでは移動しません。確定時は既存の再配置コマンドを使い、編集許可・機能設定・Undo/Redoを適用します。

## 予定の長さを変える

週・日表示の時刻指定予定には、上端と下端にリサイズ用のグリップがあります。上端は開始、下端は終了だけを15分刻みで動かし、ドラッグ中に候補の時間帯を表示します。離した時点で1回の `event.update` として確定するため、Undoも1回で戻ります。端へ移動すると縦方向へ自動スクロールします。表示中の1日内で伸縮し、日をまたぐ予定では最初の日の上端・最後の日の下端を操作できます。終日予定と、翌日以降まで広げる操作は日時入力から行います。

開始と終了の逆転は許可しません。Escape、表示期間・対象データ・編集権限の変更、ウィンドウのフォーカス喪失では確定せず中止します。夏時間で存在しない時刻への変更はエラーにします。マウス以外でもクイック入力・詳細設定の日付時刻欄で同じ変更ができます。

## 右クリック

予定では「詳細を開く」「複製」「削除」、日付や時間枠の余白では、その位置への予定作成を表示します。複製には新しいIDを付け、元の予定は変えません。更新・削除・複製は通常操作と同じ編集許可、機能設定、履歴を通ります。読み取り専用では閲覧項目だけを残し、`features.events: false` では編集項目を表示しません。メニューはEscape・外側クリックで閉じ、矢印キーとEnterでも選べます。
