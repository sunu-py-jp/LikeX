# LikeAIChat 利用ガイド

LikeAIChatは会話の下書きを編集するReactコンポーネントです。UIと公開コマンドは同じモデルを使い、応答生成・アップロード・保存先は親アプリが用意します。

| 目的 | ガイド |
| --- | --- |
| パッケージ・ソースコピー・最初の表示 | [導入と初期表示](getting-started.md) |
| サーバー・CLI・表示中の会話を操作する | [モデルAPI・コマンド・履歴](headless.md) |
| JSONを検証・保存する | [ネイティブ保存形式](native-files.md) |
| 応答生成と添付処理を接続する | [ストリーミング・再試行・添付](streaming.md) |
| 保存・権限・未保存状態をつなぐ | [保存・編集許可・イベント](lifecycle.md) |
