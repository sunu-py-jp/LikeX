# セル・範囲・行列の選択

[利用ガイドへ戻る](./README.md)

連続した範囲と、離れた複数の範囲を選択できます。Windows/LinuxではCtrl、macOSではCmdを追加選択に使います。

| 操作 | 結果 |
| --- | --- |
| セルをクリック | そのセルだけを選択 |
| セルからドラッグ | 長方形の範囲を選択 |
| Shift＋クリック／矢印キー | 最後に操作した範囲を拡張。他の追加範囲は維持 |
| Ctrl／Cmd＋クリック | 離れたセルを追加。選択済みのセルは解除 |
| Ctrl／Cmd＋ドラッグ | 離れた長方形の範囲を追加 |
| 行番号／列名をクリック | 行／列全体を選択 |
| 行番号／列名をドラッグ、またはShift＋クリック | 連続する行／列を選択 |
| 行番号／列名をCtrl／Cmd＋クリック | 離れた行／列を追加。全体が選択済みなら解除 |
| 左上の角をクリック、またはセル選択中にCtrl／Cmd＋A | シート全体を選択 |
| セル・行番号・列名を右クリック | 選択を維持してメニューを開く。既定の操作は右クリック位置に応じた範囲に実行 |

通常のクリックやShiftなしの矢印移動で、選択は1つに戻ります。セルを編集中のキー操作は文字入力が優先されます。解除で選択が空になる場合も、アクティブセル1つは残します。

選択範囲の外周を太い枠線で表示します。太枠は選択状態の表示で、セルに保存する罫線や書式は変更しません。

範囲をドラッグしている間、セル表示領域の端や外側でポインターを止めると、その方向へスクロールしながら選択を広げます。行番号からの選択は上下、列名からの選択は左右だけをスクロールします。読み取り専用でも選択できます。ポインターを離すか、Escape、ウィンドウのフォーカス喪失、シート・データ・表示倍率の変更で連続スクロールを停止します。

行番号・列名からの選択は、別の行・列にまたがる結合セルがあっても広がりません。たとえばC1:AH1が結合されていても、C列の見出しを選ぶとC列だけを選択します。通常のセル選択では、触れた結合セル全体を含めます。

## キーボードで移動する

| キー | 動作 |
| --- | --- |
| Ctrl／Cmd＋矢印 | 連続するデータの端へ移動。隣が空なら、その方向の次の非空セル、なければシートの端へ移動 |
| Ctrl／Cmd＋Shift＋矢印 | 同じ移動先まで選択範囲を拡張 |
| Home／End | 同じ行の先頭列／末尾列へ移動 |
| Ctrl／Cmd＋Home | A1へ移動 |
| Ctrl／Cmd＋End | 使用領域の右下へ移動 |
| PageUp／PageDown | 約1画面分、上／下へ移動。Shiftを押すと範囲を拡張 |
| Ctrl＋Space | 現在の列全体を選択 |
| Shift＋Space | 現在の行全体を選択 |

Ctrl／Cmd＋矢印は、セルの入力値で空かどうかを判断します。計算結果が空文字になる数式も非空として扱い、結合セルは1つのセルとして移動します。Ctrl／Cmd＋Endの使用領域には、値・書式・入力規則・コメント・結合を含みます。セルやオブジェクトの文字を編集中、IME変換中は通常の文字入力・編集を優先します。

## 複数範囲に対する操作

- 太字・配置・色等の書式変更と、Delete／Backspaceによる値の消去は、選択した全セルが対象です。範囲の間にある未選択セルは変更しません。
- 重なったセルは1回だけ処理します。下部の合計・平均・データ数も重複して数えません。
- 文字や数式の入力、関数の入力補助、コメント・画像等の挿入位置は、最後に操作したアクティブセルを使います。
- セルのコピー・切り取り・貼り付けは1つの連続した選択範囲で使います。複数範囲ではボタンを無効化し、クリップボードのショートカットにはエラーを表示します。複数の範囲を1つの長方形に変換して処理することはありません。
- ヘッダーの行列挿入・削除は1つの連続範囲で使います。[右クリックメニュー](./context-menu.md)の行列挿入・削除は、離れた対象もまとめて処理します。間にある行・列は対象にせず、一度のUndoで戻せます。

複数範囲に切り替えると、セルの内部コピー／切り取り情報は無効になります。OSのクリップボードのテキストは消しません。1つの範囲に戻ってから以前のセル内容を貼ると値のみの貼り付けになり、古い切り取り元の削除や数式参照の移動は実行しません。画像・図形・テキストボックスのコピー情報は、この切り替えでは消しません。

選択は閲覧中でも使えます。選択だけでは未保存の変更にならず、`onSave` やブックの `onChange` を発火しません。書式や値を変更した場合は、従来どおりUndo／Redo・JSON保存の対象です。

## refから表示中の選択を変更する

`SpreadsheetHandle` の選択APIは同期の `boolean` を返します。成功時は `getSelection()` に即座に反映し、通常の `onSelectionChange`／`selection`・`drawing-selection` イベントで通知します。保存データ、未保存判定、Undo／Redo履歴、編集許可は変更しません。読み取り専用でも利用できます。

| API | 対象 |
| --- | --- |
| `getSelection()` | 現在のシートID、セル・範囲・行列選択のコピー |
| `getSelectedDrawing()` | `{ sheetId, drawingId }` または `null` |
| `selectSheet(sheetId, options?)` | シートを表示してA1を選択 |
| `selectCell(sheetId, { row, column }, options?)` | 0始まりのセル位置 |
| `selectRange(sheetId, { anchor, focus, kind? }, options?)` | 1つの範囲 |
| `selectRanges(sheetId, ranges, options?)` | 同じシート内の複数範囲。最後がアクティブ |
| `selectRows(sheetId, start, end?, options?)` / `selectColumns(...)` | 両端を含む0始まりの行／列。`end` の省略時は1行／列 |
| `selectDrawing(sheetId, drawingId, options?)` | 画像・図形・テキストボックス |
| `clearSelection(options?)` | 図形と追加範囲を解除し、現在のアクティブセルを残す。セルの内容は消去しない |
| `revealSelection()` | 現在選択しているセル／図形へスクロール |

選択APIの既定動作はスクロール位置とDOMフォーカスを維持します。必要な場合だけ `options: { reveal: true }` または `revealSelection()` を使います。表示位置を動かしてもキーボードフォーカスを奪いません。

```ts
const api = spreadsheetRef.current;
if (api?.selectRanges("sheet-1", [
  { anchor: { row: 0, column: 0 }, focus: { row: 1, column: 1 } },
  { anchor: { row: 3, column: 3 }, focus: { row: 4, column: 4 } },
])) {
  console.log(api.getSelection());
  api.revealSelection();
}
```

不明なID、範囲外・小数の座標、空または129個以上の範囲、無効な `options`、無効化された図形種別、`features.sheets: false` で別シートへ移る操作は `false` です。元の選択を維持し、座標を黙って丸めません。結合セルと行列選択の解決はGUIと同じです。

セル・図形・コメント・シート名等に未確定入力がある場合やアンマウント後も `false` を返します。未確定入力を保存・破棄せず、先にGUIで確定またはキャンセルしてから選択します。GUIのクリック／キー操作は既存の入力確定後、同じ選択処理を使います。これらは表示中のref APIで、保存JSONやヘッドレスsessionには選択状態を追加しません。

## 親への通知

`onSelectionChange` で全範囲を受け取れます。位置は0始まりです。

```tsx
import Spreadsheet, {
  type SpreadsheetSelection,
  type SpreadsheetSelectionRange,
} from "@likex/spreadsheet";

function selectionChanged(selection: SpreadsheetSelection) {
  const ranges: readonly SpreadsheetSelectionRange[] = selection.ranges ?? [selection];
  console.log(selection.sheetId, ranges);
  // focus がアクティブセル。通常のセル選択では結合の左上へ解決します。
  console.log(selection.focus.row, selection.focus.column);
}

<Spreadsheet onSelectionChange={selectionChanged} style={{ height: 560 }} />;
```

例えばA1:B2とD4:E5を選択した通知は次の形です。

```json
{
  "sheetId": "sheet-1",
  "anchor": { "row": 3, "column": 3 },
  "focus": { "row": 4, "column": 4 },
  "ranges": [
    { "anchor": { "row": 0, "column": 0 }, "focus": { "row": 1, "column": 1 } },
    { "anchor": { "row": 3, "column": 3 }, "focus": { "row": 4, "column": 4 } }
  ]
}
```

従来の `sheetId`・`anchor`・`focus` はそのまま利用できます。`ranges` は以前の選択型を組み立てるコードとの互換のため型上は省略可能ですが、コンポーネントからの通知には全範囲が入ります。`anchor` は最後の範囲を伸ばす起点、`focus` はアクティブセルです。通常のセル選択では結合の左上へ解決するため、最後の範囲の `focus` と一致しない場合があります。全体の選択は `ranges` の和集合で判断してください。通知データを書き換えてもコンポーネントの選択は変更されません。

各 `SpreadsheetSelectionRange` は任意の `kind?: "row" | "column"` を持ちます。

| `range.kind` | 選択の意味 |
| --- | --- |
| 省略 | 通常のセル範囲。結合セルに触れると結合全体へ拡張 |
| `row` | 行番号から始めた選択。横断する結合によって別の行へ拡張しない |
| `column` | 列名から始めた選択。横断する結合によって別の列へ拡張しない |

`kind` は選択の始め方を表します。行・列全体を選んだ後にCtrl／Cmdで一部を解除すると、残った範囲にも `kind` が残るため、常に行全体・列全体を含むとは限りません。実際に選択したセルは各範囲の `anchor` / `focus` から判断してください。`kind` を含まない既存の選択データも使えます。[結合セルの操作](./merged-cells.md)も参照してください。

GUIでセルを貼り付けると、貼り付けた範囲全体の選択を維持します。貼り付け前のアクティブセルがその範囲内なら同じ位置を保ち、範囲外なら左上をアクティブにします。行・列全体を貼り付けたときも、範囲の末端へ自動スクロールしません。

GUIのセル操作では、操作開始時の選択を履歴に記録し、Undo／Redoの両方で復元します。空白を含む長方形、複数範囲の順序、各範囲の方向と `kind`、アクティブセルを保持します。変更セルの差分やUndo／Redo直前の選択から範囲を作り直しません。貼り付けでは実際の転送先範囲を記録し、Undo／Redoでもその範囲を選択します。

GUIの行列の挿入・削除、結合、シート構成の変更でも、記録した選択を復元します。復元先のシートが小さい場合は有効な範囲へ補正し、Redoで寸法が戻れば元の記録範囲を復元します。貼り付けの自動拡張をUndoする場合も同じです。復元対象のシートがなくなる場合は先頭シートのA1を選択します。

外部APIコマンドの履歴にはGUI選択の記録を使わず、セルの変更対象へ移動します。複数シートでは表示中のシートを優先し、対象でなければ最初の対象シートへ移ります。描画オブジェクトだけの変更では、その画像・図形・テキストボックスを選択し、取り消しによってなくなる場合はアンカーのセルを選択します。[Undo／Redoの選択ルール](./history-session.md#guiとの境界)に操作別の違いをまとめています。

選択の記録はコンポーネント内の履歴に保持しますが、ブックの保存JSONや公開の画面なしセッションには含めません。コンポーネント外にDOMフォーカスがある場合は、そのフォーカスを奪いません。

シート切り替え・保存成功・再読み込み・変更の破棄は従来どおり選択をリセットします。

## 上限

選択範囲は最大128個です。範囲からセルを解除すると、残りを複数の長方形に分けることがあります。操作後に上限を超える場合は、元の選択を維持してエラーを表示します。

大きな行列全体の選択も可能ですが、書式変更・値の消去など一度に処理するセルは、重複を除いて10,000セルまでです。それを超える選択は、下部に選択セル数だけを表示します。
