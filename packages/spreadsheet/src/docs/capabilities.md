# 操作と初版の制約

[利用ガイドへ戻る](./README.md)

## 操作

セルの初回クリックはセルだけを選択し、文字列は全選択しません。選択中のセルをもう一度クリックすると、その位置にカーソルを置いて編集できます。選択状態からの文字入力は値を置き換え、F2は既存の値の末尾から編集します。Enter / Tabで確定、Escapeでキャンセルします。矢印キーで選択を移動し、ドラッグやShiftで範囲を選択できます。Delete / Backspaceは選択範囲の値を消去します。Ctrl / Cmd + Sで保存、Ctrl / Cmd + Zでundo、Ctrl / Cmd + Shift + ZまたはCtrl + Yでredoでき、連続した履歴操作でもグリッドのフォーカスを維持します。

Ctrl / Cmdを押しながら離れたセル・範囲・行列を追加選択できます。書式変更・値の消去・下部の集計は選択した全セルが対象です。コピー／切り取り／貼り付けと行列の挿入・削除は1つの連続範囲で使います。[選択方法と親への通知](./selection.md) に操作・型・上限をまとめています。

TSV形式のコピー・切り取り・貼り付けに対応します。クリップボードのボタンはブラウザの権限や安全なコンテキストに依存するため、利用できない環境ではキーボードのコピー／貼り付けを使ってください。同じコンポーネント内でコピー元の識別情報を保てる場合、数式の相対参照を移動して貼り付けます。外部へは計算結果をTSVのテキストとして渡します。

書式は太字・斜体・下線、左右中央の配置、文字色・背景色、標準・数値・通貨・パーセントに対応します。行列の挿入・削除、列幅の変更、シートの追加・改名・削除を備えます。選択済みのシートタブをもう一度クリックすると、その場でシート名を編集できます。Enterまたはフォーカス移動で確定し、Escapeでキャンセルします。シートの右クリックメニューから削除できます。最後の1シートは削除できません。

シートタブをドラッグすると、挿入位置を示す線に合わせて順番を変更できます。タブにフォーカスした状態のAlt + Shift + 左右キーでも移動できます。セルやシート名の編集中は入力を確定してから並べ替えます。順番はJSONの `sheets` 配列に保存され、Undo／Redoに対応します。`features={{ reorderSheets: false }}` で並べ替えを無効にできます。

連続した範囲のセル結合・解除にも対応します。左上以外の内容を削除する場合は確認します。[結合セルの操作・コピー・JSON形式](./merged-cells.md) を参照してください。

ヘッダーは「ホーム」と「挿入」に分かれています。画像・図形・テキストボックス・セルコメントも保存とUndo／Redoの対象です。[挿入機能とJSON保存](./insertions-and-json.md) に操作と形式をまとめています。

## 数式

四則演算・比較・セル参照・範囲・シート参照と、集計・条件分岐・文字列処理等の基本15関数を備えます。「ホーム」の「関数」から式の例を入力できます。[基本関数と数式](./functions.md) に一覧、参照の書き方、JSON保存、計算エラーと対応範囲をまとめています。

## 制約

- `.xlsx` 入出力、グラフ、ピボットテーブル、マクロ、条件付き書式、共同編集は含みません。
- 1シート最大10,000行・1,000列、1ブック最大100シート・100,000件の保持セルです。一度の範囲操作と数式の範囲評価は10,000セルまでです。セル文字数や式の長さ・計算量にも上限があり、公開定数 `SPREADSHEET_LIMITS` で確認できます。
- 行は仮想表示しますが、列・計算・保存は大きなブックで負荷が増えます。上限は快適な操作を保証する性能値ではありません。対象データで確認してください。
- undo/redoは最大50段階のメモリ内履歴です。保存成功・再マウントでリセットします。
- `rowHeights` は画面へ反映しますが、画面上の行高変更は提供しません。
- 切り取りで数式参照を追従させる際、参照範囲の一部分だけを別の場所へ分離する操作は拒否します。例えば `SUM(A1:A3)` が参照するA2だけの移動はできません。範囲全体の移動は可能です。
- 外部から受け取ったテキストの `=` で始まる値は数式として扱います。利用先でデータ形式・許容する値を検証してください。
