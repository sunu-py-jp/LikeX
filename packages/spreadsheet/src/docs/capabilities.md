# 操作と初版の制約

[利用ガイドへ戻る](./README.md)

## 操作

セルのクリック、矢印キーで選択を移動し、ドラッグやShiftで範囲を選択できます。入力・F2・ダブルクリックで編集し、Enter / Tabで確定、Escapeでキャンセルします。Delete / Backspaceは選択範囲の値を消去します。Ctrl / Cmd + Sで保存、Ctrl / Cmd + Zでundo、Ctrl / Cmd + Shift + ZまたはCtrl + Yでredoできます。

TSV形式のコピー・切り取り・貼り付けに対応します。クリップボードのボタンはブラウザの権限や安全なコンテキストに依存するため、利用できない環境ではキーボードのコピー／貼り付けを使ってください。同じコンポーネント内でコピー元の識別情報を保てる場合、数式の相対参照を移動して貼り付けます。外部へは計算結果をTSVのテキストとして渡します。

書式は太字・斜体・下線、左右中央の配置、文字色・背景色、標準・数値・通貨・パーセントに対応します。行列の挿入・削除、列幅の変更、シートの追加・改名・削除を備えます。最後の1シートは削除できません。

ヘッダーは「ホーム」と「挿入」に分かれています。画像・図形・テキストボックス・セルコメントも保存とUndo／Redoの対象です。[挿入機能とJSON保存](./insertions-and-json.md) に操作と形式をまとめています。

## 数式

四則演算・比較・セル参照・範囲・シート参照と、集計・条件分岐・文字列処理等の基本15関数を備えます。「ホーム」の「関数」から式の例を入力できます。[基本関数と数式](./functions.md) に一覧、参照の書き方、JSON保存、計算エラーと対応範囲をまとめています。

## 制約

- `.xlsx` 入出力、グラフ、ピボットテーブル、マクロ、結合セル、条件付き書式、共同編集は含みません。
- 1シート最大10,000行・1,000列、1ブック最大100シート・100,000件の保持セルです。一度の範囲操作と数式の範囲評価は10,000セルまでです。セル文字数や式の長さ・計算量にも上限があり、公開定数 `SPREADSHEET_LIMITS` で確認できます。
- 行は仮想表示しますが、列・計算・保存は大きなブックで負荷が増えます。上限は快適な操作を保証する性能値ではありません。対象データで確認してください。
- undo/redoは最大50段階のメモリ内履歴です。保存成功・再マウントでリセットします。
- `rowHeights` は画面へ反映しますが、画面上の行高変更は提供しません。
- 切り取りで数式参照を追従させる際、参照範囲の一部分だけを別の場所へ分離する操作は拒否します。例えば `SUM(A1:A3)` が参照するA2だけの移動はできません。範囲全体の移動は可能です。
- 外部から受け取ったテキストの `=` で始まる値は数式として扱います。利用先でデータ形式・許容する値を検証してください。
