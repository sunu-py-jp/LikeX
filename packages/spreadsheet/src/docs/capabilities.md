# 操作と対応範囲

[利用ガイドへ戻る](./README.md)

## 操作

セルの初回クリックはセルだけを選択し、文字列は全選択しません。選択中のセルをもう一度クリックすると、その位置にカーソルを置いて編集できます。選択状態からの文字入力は値を置き換え、F2は既存の値の末尾から編集します。Enter / Tabで確定、Escapeでキャンセルします。Alt + Enterでセル内に改行を挿入できます。矢印キーで選択を移動し、ドラッグやShiftで範囲を選択できます。Delete / Backspaceは選択範囲の値を消去します。Ctrl / Cmd + Sで保存、Ctrl / Cmd + Zでundo、Ctrl / Cmd + Shift + ZまたはCtrl + Yでredoできます。GUIのセル操作をUndo／Redoすると、操作時に記録した選択を復元します。空白や複数範囲も保持し、貼り付けでは実際の転送先範囲を選択します。行列・シート構成の変更も記録した選択を復元先の有効な範囲へ補正します。描画オブジェクトだけの変更では、その対象へ選択を移します。[履歴操作後の選択](./history-session.md#guiとの境界)を参照してください。

Ctrl / Cmdを押しながら離れたセル・範囲・行列を追加選択できます。書式変更・値の消去・下部の集計は選択した全セルが対象です。セルのコピー／切り取り／貼り付けと、ヘッダーの行列挿入・削除は1つの連続範囲で使います。右クリックメニューの行列挿入・削除は離れた対象も処理できます。[選択方法と親への通知](./selection.md) に操作・型・上限をまとめています。

Ctrl／Cmd＋矢印で連続データの端へ、Ctrl／Cmd＋HomeでA1へ、Ctrl／Cmd＋Endで使用領域の右下へ移動できます。Shiftを加えた範囲拡張、PageUp／PageDown、Ctrl＋Spaceによる列選択、Shift＋Spaceによる行選択も使えます。選択範囲の外周は太枠で表示します。

TSV形式のコピー・切り取り・貼り付けに対応します。クリップボードのボタンはブラウザの権限や安全なコンテキストに依存するため、利用できない環境ではキーボードのコピー／貼り付けを使ってください。同じコンポーネント内でコピー元の識別情報を保てる場合、数式の相対参照を移動して貼り付けます。外部へは計算結果をTSVのテキストとして渡します。

グリッドの[表示倍率](./zoom.md)は25〜200％で変更できます。右下のスライダーの中央は100％で、倍率ボタンを押すと100％へ戻ります。グリッド上のCtrl＋ホイールやトラックパッドのピンチも使えます。倍率は表示だけに適用し、保存データやUndo履歴は変えません。

[書式](./formatting.md)は罫線・フォント・折り返し・縦横の配置・標準／文字列／数値／通貨／パーセント／日付／時刻／日時の表示形式・条件付き書式に対応します。行列の挿入・削除、幅・高さの変更と自動調整、シートの追加・改名・複製・削除を備えます。選択済みのシートタブをもう一度クリックすると、その場でシート名を編集できます。Enterまたはフォーカス移動で確定し、Escapeでキャンセルします。シートの右クリックメニューから複製・削除できます。最後の1シートは削除できません。

シートタブをドラッグすると、挿入位置を示す線に合わせて順番を変更できます。タブにフォーカスした状態のAlt + Shift + 左右キーでも移動できます。セルやシート名の編集中は入力を確定してから並べ替えます。順番はJSONの `sheets` 配列に保存され、Undo／Redoに対応します。`features={{ reorderSheets: false }}` で並べ替えを無効にできます。

シート一覧が幅に収まらないときは、左右の矢印から次の見切れているシートまで横スクロールできます。矢印は移動できる方向にだけ表示し、表示しない側には余白を残しません。シート名に重ねず、一覧の高さも変更しません。スクロールだけではアクティブシートを切り替えず、ブックや変更履歴も変わりません。

連続した範囲のセル結合・解除にも対応します。左上以外の内容を削除する場合は確認します。[結合セルの操作・コピー・JSON形式](./merged-cells.md) を参照してください。

外部から表を配置する `cells.writeGrid` は、上・左の階層見出し・マトリクス・通常列とマトリクス列の混在に対応します。見出しツリーから結合範囲を自動計算し、本文と格子罫線・色をまとめて設定します。親グループだけ上・左に張り出す配置も指定できます。作成後は通常のセル・結合として表示・編集・保存します。[各パターンの指定例](./tables.md#階層見出しとマトリクス)を参照してください。

ヘッダーは「ファイル」「ホーム」「挿入」「データ」「ページ レイアウト」に分かれています。[検索・置換・形式を選択して貼り付け・ドラッグでオートフィル](./editing-tools.md)はホーム、[入力規則・プルダウン・チェックボックス](./input-validation.md)の設定はデータにあります。[印刷範囲と改ページ](./print-area.md)はページ レイアウトから設定し、枠のドラッグで調整できます。画像・図形・テキストボックス・セルコメントも保存とUndo／Redoの対象です。[挿入機能とJSON保存](./insertions-and-json.md) に操作と形式をまとめています。

[名前付き範囲](./named-ranges.md)も「データ」から追加できます。「管理」は右側にブック全体の一覧を開き、項目から範囲を選択し、鉛筆ボタンから定義を編集できます。範囲の途中に行・列を挿入すると、定義も自動で拡張します。

[範囲のフィルター](./filters.md)は「データ」から設定し、先頭行の各列ボタンで値を絞り込みます。見出し1行だけの選択では下のデータ範囲まで広げます。読み取り専用では表示中だけの絞り込みとなり、元のブックを変更しません。

## 数式

四則演算・比較・セル参照・範囲・シート参照と、条件付き集計・検索・文字列・日付・行列番号などの関数を備えます。「ホーム」の「関数」から用途別に式の例を入力できます。[関数と数式](./functions.md) に一覧、参照の書き方、JSON保存、計算エラーと対応範囲をまとめています。

## 制約

- `.xlsx` は[取り込み](./excel-import.md)と[出力](./excel-export.md)に対応します。Excelの完全互換ではありません。グラフ、ピボットテーブル、マクロ、共同編集は含みません。
- 1シート最大10,000行・1,000列、1ブック最大100シート・100,000件の保持セルです。一度の範囲操作と数式の範囲評価は10,000セルまでです。セル文字数や式の長さ・計算量にも上限があり、公開定数 `SPREADSHEET_LIMITS` で確認できます。
- 既定の `renderingMode="viewport"` は表示領域とその前後、アクティブセルや表示中の結合に必要な行だけを描画する省メモリ表示です。`renderingMode="progressive"` を指定すると、表示範囲を先に描画し、現在のシートの画面外の行も順次追加して保持します。列はどちらも全列を描画するため、列数を増やすと対象行のセルDOMが比例して増えます。行数の増加も座標計算には影響し、データ量・数式・保存にも負荷があります。上限は快適な操作を保証する性能値ではありません。[描画モードの指定](./api.md#シートの描画モード)を参照してください。
- Undo／Redoは最大50段階のメモリ内履歴です。保存後もコンポーネントを閉じるまで保持します。再読み込み・変更の破棄・編集許可時の別ブックへの置き換え・再マウントではリセットします。[履歴の詳細](./history-session.md#guiとの境界)
- 切り取りで数式参照を追従させる際、参照範囲の一部分だけを別の場所へ分離する操作は拒否します。例えば `SUM(A1:A3)` が参照するA2だけの移動はできません。範囲全体の移動は可能です。
- 外部から受け取った `=` で始まる値は、文字列書式や先頭アポストロフィで文字列として指定しない場合、数式として扱います。利用先でデータ形式・許容する値を検証してください。
