# 基本関数と数式

[利用ガイドへ戻る](./README.md)

セルまたは数式バーに `=` から始まる式を入力すると、値の変更に合わせて計算結果を表示します。「ホーム」の「関数」から用途を選ぶと、選択セルに式の例を入力できます。参照先や引数を編集し、Enterまたはフォーカスを外す操作で確定します。Escapeで取り消せます。

デモの「関数サンプル」シートには、対応する15関数の用途・式・計算結果を並べています。G列の入力を変更して、再計算を試せます。C列は式を文字列として表示し、D列が実際に計算するセルです。

## 対応関数

次の表では、A1が `10`、A2が `20`、A3が空セル、A4が `メモ` の場合を例にしています。関数名の大文字・小文字は区別しません。

| 関数 | 用途 | 式の例 | 結果 |
| --- | --- | --- | --- |
| `SUM` | 数値の合計 | `=SUM(A1:A3)` | `30` |
| `AVERAGE` | 数値の平均 | `=AVERAGE(A1:A3)` | `15` |
| `MIN` | 最小値 | `=MIN(A1:A3)` | `10` |
| `MAX` | 最大値 | `=MAX(A1:A3)` | `20` |
| `COUNT` | 数値の個数 | `=COUNT(A1:A4)` | `2` |
| `COUNTA` | 空でない値の個数 | `=COUNTA(A1:A4)` | `3` |
| `ROUND` | 指定した桁で四捨五入 | `=ROUND(-12.345,2)` | `-12.35` |
| `ABS` | 絶対値 | `=ABS(-12.345)` | `12.345` |
| `IF` | 条件による分岐 | `=IF(A1>=10,"達成","未達")` | `達成` |
| `IFERROR` | エラー時に別の値を表示 | `=IFERROR(A1/0,"計算できません")` | `計算できません` |
| `AND` | 全ての条件を満たすか | `=AND(A1>0,A2>0)` | `TRUE` |
| `OR` | いずれかの条件を満たすか | `=OR(A1>=20,A2>=20)` | `TRUE` |
| `NOT` | 条件の反転 | `=NOT(A1<0)` | `TRUE` |
| `LEN` | 文字数 | `=LEN("LikeX")` | `5` |
| `CONCAT` | 文字列を連結 | `=CONCAT("Like","X")` | `LikeX` |

関数の組み合わせも使えます。例えば `=IFERROR(ROUND(SUM(A1:A3)/A2,2),0)` です。

### 引数と空セルの扱い

- `SUM` / `AVERAGE` / `MIN` / `MAX` / `COUNT` は数値を対象にします。空セル・文字列・論理値は集計しません。通常入力した `10` は数値ですが、`'10` や式の `"10"` は文字列です。
- `COUNTA` は1引数以上で、セル・範囲・直接指定した値を数えます。空セルは除き、数式が返す空文字 `""`、文字列、論理値、通常の計算エラーは数えます。計算上限や循環参照のエラーはそのまま返します。
- `ROUND(数値, 桁数)` は2引数です。正の桁数は小数部、`0` は整数、負の桁数は十・百等の位を丸めます。`=ROUND(1234,-2)` は `1200` です。桁数の小数部分は0方向に切り捨てます。`ABS` は1引数です。
- `IF(条件, 真の場合, 偽の場合)` は2～3引数で、偽の場合を省略すると `FALSE` を返します。数値・論理値で条件を判定し、選ばれた側だけを計算します。`IFERROR(値, エラー時の値)` も、必要になった場合だけエラー時の値を計算します。
- `AND` / `OR` は1引数以上、`NOT` は1引数です。数値の `0` は偽、それ以外は真として扱います。`AND` / `OR` は参照セル・範囲にある文字列と空セルを無視し、有効な値がなければ `#VALUE!` を返します。全引数を評価するため、条件の途中にあるエラーを隠しません。
- `LEN` は1引数で、Unicodeのコードポイント数を数えます。絵文字のサロゲートペアは1つ、結合文字や複数の絵文字をつなぐ記号は個別に数えるため、見た目の文字数と異なる場合があります。
- `CONCAT` は1引数以上で、範囲も受け付けます。範囲は各行の左から右へ、上の行から下の行へ連結します。論理値は `TRUE` / `FALSE` の文字列になります。`LEN` / `CONCAT` / `IFERROR` の空セル参照は空文字として扱います。

## 参照と演算子

基本四則演算、べき乗 `^`、パーセント `%`、比較 `= <> < > <= >=`、文字列の連結 `&` に対応します。括弧で計算順を指定できます。文字列はダブルクォートで囲み、文字列中の `"` は `""` と書きます。

```text
=SUM(B2:B10)
=$B$2*C3
='前年 売上'!B2
=IF(AND(B2>0,C2>0),B2*C2,0)
=CONCAT("合計: ",SUM(B2:B10))
```

セル・範囲・他のシートを参照できます。`$` で行または列を固定でき、コンポーネント内でのコピーでは相対参照が移動します。シート名に空白や日本語がある場合は、上の例のようにシングルクォートで囲めます。

式を計算せず文字列として表示する場合は、先頭にシングルクォートを加えます。例えばセルの値を `'=SUM(A1:A3)` にすると、画面には `=SUM(A1:A3)` と表示されます。

## JSONへの保存

セルの `value` には、計算結果ではなく入力した式の文字列を保持します。`serializeWorkbook` / `parseWorkbook` でJSONを保存・復元でき、コンポーネントは復元した式を再計算して表示します。計算結果をブックの別フィールドに二重保存する必要はありません。

```ts
import {
  calculateWorkbook, parseWorkbook, serializeWorkbook,
  type SpreadsheetWorkbook,
} from "@likex/spreadsheet";

const workbook: SpreadsheetWorkbook = {
  schemaVersion: 1,
  sheets: [{
    id: "budget", name: "予算", rowCount: 100, columnCount: 26,
    cells: {
      A1: { value: "1200" },
      A2: { value: "300" },
      A3: { value: "=SUM(A1:A2)" },
    },
  }],
};

const json = serializeWorkbook(workbook);
const restored = parseWorkbook(json);
restored.sheets[0].cells.A3.value; // "=SUM(A1:A2)"
const values = calculateWorkbook(restored);
values.budget.A3; // 1500
```

`calculateWorkbook` は `sheetId` → A1アドレス → 計算結果のオブジェクトを返します。式の文字列を持つ元のブックは変更しません。保存コールバックへの接続例は [公開API](./api.md#保存)、画像等も含む形式は [JSON保存](./insertions-and-json.md) を参照してください。

## 機能設定と対応範囲

`features={{ formulas: false }}` で数式入力と関数の入力補助を無効化できます。初期ブックに含まれる数式の計算結果は引き続き表示します。`readOnly` または `onSave` の省略でも編集できなくなります。

Excelの関数・型変換・表示規則の完全互換ではありません。日付関数、検索関数、動的配列、外部ブック参照、利用側による独自関数の登録は提供していません。数値はJavaScriptの浮動小数点数で計算するため、小数の演算には丸め誤差が生じることがあります。

未対応の関数は `#NAME?`、不正な値は `#VALUE!`、ゼロ除算は `#DIV/0!`、不正な参照は `#REF!`、循環参照は `#CYCLE!` として表示します。式の長さ・参照の深さ・範囲の大きさ・計算量等には上限があり、超過は `#LIMIT!` になります。公開定数 `SPREADSHEET_LIMITS` で上限を確認できます。JavaScriptの `eval` / `Function` は使用しません。

`IFERROR` が代替値に置き換えるのは `#REF!` / `#DIV/0!` / `#VALUE!` / `#NAME?` / `#NUM!` / `#N/A` です。安全のための `#LIMIT!`、循環参照の `#CYCLE!`、構文等の `#ERROR!` は置き換えません。式全体が構文として読み取れない場合も、分岐に入る前にエラーになります。
