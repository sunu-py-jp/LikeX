# 関数と数式

[利用ガイドへ戻る](./README.md)

セルまたは数式バーに `=` から始まる式を入力すると、値の変更に合わせて計算結果を表示します。「ホーム」の「関数」は用途別に分類されています。関数を選ぶと選択セルに式の例を入力できます。参照先や引数を編集し、Enterまたはフォーカスを外す操作で確定します。Escapeで取り消せます。

デモの「関数サンプル」シートには、対応する全関数の用途・式・計算結果を並べています。G列とI〜O列の入力を変更して、再計算を試せます。C列は式を文字列として表示し、D列が実際に計算するセルです。

## 基本の集計・演算

次の表では、A1が `10`、A2が `20`、A3が空セル、A4が `メモ` の場合を例にしています。関数名の大文字・小文字は区別しません。

| 関数 | 用途 | 式の例 | 結果 |
| --- | --- | --- | --- |
| `SUM` | 数値の合計 | `=SUM(A1:A3)` | `30` |
| `AVERAGE` | 数値の平均 | `=AVERAGE(A1:A3)` | `15` |
| `MIN` | 最小値 | `=MIN(A1:A3)` | `10` |
| `MAX` | 最大値 | `=MAX(A1:A3)` | `20` |
| `COUNT` | 数値の個数 | `=COUNT(A1:A4)` | `2` |
| `COUNTA` | 空でない値の個数 | `=COUNTA(A1:A4)` | `3` |
| `ROUND` | 指定した桁で四捨五入 | `=ROUND(-12.345,2)` | `-12.35` |
| `ABS` | 絶対値 | `=ABS(-12.345)` | `12.345` |
| `IF` | 条件による分岐 | `=IF(A1>=10,"達成","未達")` | `達成` |
| `IFERROR` | エラー時に別の値を表示 | `=IFERROR(A1/0,"計算できません")` | `計算できません` |
| `AND` | 全ての条件を満たすか | `=AND(A1>0,A2>0)` | `TRUE` |
| `OR` | いずれかの条件を満たすか | `=OR(A1>=20,A2>=20)` | `TRUE` |
| `NOT` | 条件の反転 | `=NOT(A1<0)` | `TRUE` |
| `LEN` | 文字数 | `=LEN("LikeX")` | `5` |
| `CONCAT` | 文字列を連結 | `=CONCAT("Like","X")` | `LikeX` |

関数の組み合わせも使えます。例えば `=IFERROR(ROUND(SUM(A1:A3)/A2,2),0)` です。

## 条件付き集計

| 関数 | 引数 | 用途 |
| --- | --- | --- |
| `COUNTIF` | `COUNTIF(範囲, 条件)` | 条件に合うセル数 |
| `COUNTIFS` | `COUNTIFS(範囲1, 条件1, [範囲2, 条件2], …)` | 全条件に合う位置のセル数 |
| `SUMIF` | `SUMIF(範囲, 条件, [合計範囲])` | 条件に合う位置の数値の合計 |
| `SUMIFS` | `SUMIFS(合計範囲, 範囲1, 条件1, …)` | 全条件に合う位置の数値の合計 |
| `AVERAGEIF` | `AVERAGEIF(範囲, 条件, [平均範囲])` | 条件に合う位置の数値の平均 |
| `AVERAGEIFS` | `AVERAGEIFS(平均範囲, 範囲1, 条件1, …)` | 全条件に合う位置の数値の平均 |
| `COUNTBLANK` | `COUNTBLANK(範囲)` | 空セルと、式が返した空文字の数 |

```text
=COUNTIF(A2:A20,"完了")
=COUNTIFS(A2:A20,"完了",B2:B20,">=1000")
=SUMIF(A2:A20,"完了",B2:B20)
=SUMIFS(C2:C20,A2:A20,"東京",B2:B20,">=10")
=AVERAGEIF(B2:B20,">0")
```

条件には数値・文字列・`">=10"` / `"<>完了"` などの比較文字列を使えます。文字列の大文字小文字は区別しません。`*` は任意の文字列、`?` は任意の1文字、`~*` / `~?` は記号そのものです。複数条件はANDで判定します。空セルも含む位置関係を保って比較するため、途中に空白があっても合計先がずれません。

比較する範囲・合計範囲・平均範囲は同じ行数・列数で指定してください。Excelの `SUMIF` のように、短い合計範囲の外側へ自動的に拡張する指定は扱いません。該当する数値がない平均は `#DIV/0!` になります。

## 数値の処理

| 関数 | 引数 | 例と結果 |
| --- | --- | --- |
| `ROUNDUP` | `ROUNDUP(数値, 桁数)` | `ROUNDUP(-12.341,2)` → `-12.35`（0から離す） |
| `ROUNDDOWN` | `ROUNDDOWN(数値, 桁数)` | `ROUNDDOWN(-12.349,2)` → `-12.34`（0へ近づける） |
| `INT` | `INT(数値)` | `INT(-1.2)` → `-2` |
| `MOD` | `MOD(数値, 除数)` | `MOD(10,3)` → `1`。結果の符号は除数に従う |
| `PRODUCT` | `PRODUCT(値1, [値2], …)` | `PRODUCT(2,3,4)` → `24`。範囲指定可 |

## 文字列の処理

| 関数 | 引数 | 用途 |
| --- | --- | --- |
| `LEFT` / `RIGHT` | `LEFT(文字列, [文字数])` | 左／右から取り出す。文字数省略時は1 |
| `MID` | `MID(文字列, 開始位置, 文字数)` | 指定位置から取り出す |
| `TRIM` | `TRIM(文字列)` | 前後の半角空白を除き、連続する半角空白を1つにする |
| `UPPER` / `LOWER` | `UPPER(文字列)` | 大文字／小文字に変換 |
| `SUBSTITUTE` | `SUBSTITUTE(文字列, 検索文字列, 置換文字列, [出現番号])` | 全出現または指定した出現を置換 |
| `FIND` | `FIND(検索文字列, 対象文字列, [開始位置])` | 大文字小文字を区別して位置を取得 |
| `SEARCH` | `SEARCH(検索文字列, 対象文字列, [開始位置])` | 大文字小文字を区別せず位置を取得。ワイルドカード可 |
| `TEXTJOIN` | `TEXTJOIN(区切り文字, 空を無視するか, 値1, …)` | 範囲を含む値を区切って結合 |
| `VALUE` | `VALUE(文字列)` | 数値の文字列を数値へ変換 |

文字の開始位置と出現番号は1始まりです。`FIND` / `SEARCH` で見つからない場合は `#VALUE!` を返します。`VALUE` は数値の文字列を対象とし、通貨記号や地域依存の日付表記の自動解釈は行いません。

## 条件分岐・判定

| 関数 | 引数 | 用途 |
| --- | --- | --- |
| `IFNA` | `IFNA(値, 見つからない場合の値)` | `#N/A` の場合だけ代替値を返す |
| `IFS` | `IFS(条件1, 値1, [条件2, 値2], …)` | 最初に満たした条件の値。該当なしは `#N/A` |
| `ISBLANK` | `ISBLANK(値)` | 空セルかを判定。数式の空文字は空セルに含めない |
| `ISNUMBER` | `ISNUMBER(値)` | 数値かを判定。文字列 `"10"` はFALSE |
| `ISTEXT` | `ISTEXT(値)` | 文字列かを判定 |
| `ISERROR` | `ISERROR(値)` | 通常の計算エラーかを判定 |

`IFNA` / `IFS` は結果に必要な分岐だけを計算します。`ISERROR` を含め、計算量上限や循環参照を隠すことはできません。

## 検索・参照

| 関数 | 引数 | 用途 |
| --- | --- | --- |
| `INDEX` | `INDEX(範囲, 行番号, [列番号])` | 範囲内の指定位置の値を返す。番号は1始まり |
| `MATCH` | `MATCH(検索値, 検索範囲, [照合方法])` | 1行または1列の範囲内の位置を返す |
| `VLOOKUP` | `VLOOKUP(検索値, 表範囲, 列番号, [近似一致])` | 表の先頭列を検索し、同じ行の値を返す |
| `HLOOKUP` | `HLOOKUP(検索値, 表範囲, 行番号, [近似一致])` | 表の先頭行を検索し、同じ列の値を返す |
| `XLOOKUP` | `XLOOKUP(検索値, 検索範囲, 戻り範囲, [未一致時の値], [一致モード], [検索モード])` | 検索列と戻す列を別々に指定。横方向も可 |

```text
=VLOOKUP("商品A",A2:C20,3,FALSE)
=INDEX(C2:C20,MATCH("商品A",A2:A20,0))
=XLOOKUP("商品A",A2:A20,C2:C20,"該当なし")
```

`MATCH` の照合方法は `0` が完全一致、`1`（省略時）が検索値以下、`-1` が検索値以上の近似一致です。近似一致では検索範囲をそれぞれ昇順・降順に整列してください。`VLOOKUP` / `HLOOKUP` は `FALSE` で完全一致、`TRUE`（省略時）で昇順の近似一致です。

`XLOOKUP` は省略時に完全一致です。一致モードは `0`（完全一致）・`-1`（完全一致または次に小さい値）・`1`（完全一致または次に大きい値）・`2`（ワイルドカード）。検索モードは `1`（先頭から）・`-1`（末尾から）です。バイナリ検索モードには対応しません。

`INDEX` の対象が複数行・複数列なら、行番号と列番号の両方を指定します。`XLOOKUP` の検索範囲と戻り範囲は、同じ行数・列数の1行または1列にします。

この実装の検索関数は1つのセル値を返します。`INDEX` の行・列番号に0を指定して配列を返す機能、`XLOOKUP` の複数列を返す機能やスピルは対象外です。

## 日付

| 関数 | 引数 | 用途 |
| --- | --- | --- |
| `DATE` | `DATE(年, 月, 日)` | Excelの1900日付シリアル値を返す |
| `YEAR` | `YEAR(日付シリアル値)` | 年 |
| `MONTH` | `MONTH(日付シリアル値)` | 月（1〜12） |
| `DAY` | `DAY(日付シリアル値)` | 日 |

```text
=DATE(2026,9,15)
=YEAR(DATE(2026,9,15))
=MONTH(DATE(2026,9,15))
=DAY(DATE(2026,9,15))
```

`DATE` の結果は数値です。セルの表示形式を「日付」にすると日付として表示されます。月・日のはみ出しは前後の月へ繰り越します。計算はタイムゾーンに依存せず、1904日付方式や地域依存の文字列からの日付解析には対応しません。

## 行番号・列番号と範囲の大きさ

| 式 | 戻り値 |
| --- | --- |
| `=ROW()` | 数式を入力したセルの行番号 |
| `=COLUMN()` | 数式を入力したセルの列番号（A=1、B=2、…） |
| `=ROW(C5)` / `=ROW(C5:E9)` | `5`。範囲指定時は先頭行 |
| `=COLUMN(C5)` / `=COLUMN(C5:E9)` | `3`。範囲指定時は先頭列 |
| `=ROWS(C5:E9)` | `5`。範囲の行数 |
| `=COLUMNS(C5:E9)` | `3`。範囲の列数 |

番号はすべて1始まりです。外部コマンドの `row` / `column` は0始まりなので区別してください。参照範囲の値を数える関数ではなく、空セルも含む範囲の位置・大きさを返します。行列を挿入・削除した場合も、その時点の参照位置で再計算します。

## 基本関数の引数と空セルの扱い

- `SUM` / `AVERAGE` / `MIN` / `MAX` / `COUNT` は数値を対象にします。空セル・文字列・論理値は集計しません。通常入力した `10` は数値ですが、`'10` や式の `"10"` は文字列です。
- `COUNTA` は1引数以上で、セル・範囲・直接指定した値を数えます。空セルは除き、数式が返す空文字 `""`、文字列、論理値、通常の計算エラーは数えます。計算上限や循環参照のエラーはそのまま返します。
- `ROUND(数値, 桁数)` は2引数です。正の桁数は小数部、`0` は整数、負の桁数は十・百等の位を丸めます。`=ROUND(1234,-2)` は `1200` です。桁数の小数部分は0方向に切り捨てます。`ABS` は1引数です。
- `IF(条件, 真の場合, 偽の場合)` は2～3引数で、偽の場合を省略すると `FALSE` を返します。数値・論理値で条件を判定し、選ばれた側だけを計算します。`IFERROR(値, エラー時の値)` も、必要になった場合だけエラー時の値を計算します。
- `AND` / `OR` は1引数以上、`NOT` は1引数です。数値の `0` は偽、それ以外は真として扱います。`AND` / `OR` は参照セル・範囲にある文字列と空セルを無視し、有効な値がなければ `#VALUE!` を返します。全引数を評価するため、条件の途中にあるエラーを隠しません。
- `LEN` は1引数で、Unicodeのコードポイント数を数えます。絵文字のサロゲートペアは1つ、結合文字や複数の絵文字をつなぐ記号は個別に数えるため、見た目の文字数と異なる場合があります。
- `CONCAT` は1引数以上で、範囲も受け付けます。範囲は各行の左から右へ、上の行から下の行へ連結します。論理値は `TRUE` / `FALSE` の文字列になります。`LEN` / `CONCAT` / `IFERROR` の空セル参照は空文字として扱います。

## 参照と演算子

基本四則演算、べき乗 `^`、パーセント `%`、比較 `= <> < > <= >=`、文字列の連結 `&` に対応します。括弧で計算順を指定できます。文字列はダブルクォートで囲み、文字列中の `"` は `""` と書きます。

```text
=SUM(B2:B10)
=$B$2*C3
='前年 売上'!B2
=IF(AND(B2>0,C2>0),B2*C2,0)
=CONCAT("合計: ",SUM(B2:B10))
```

セル・範囲・他のシートを参照できます。`$` で行または列を固定でき、コンポーネント内でのコピーでは相対参照が移動します。シート名に空白や日本語がある場合は、上の例のようにシングルクォートで囲めます。

式を計算せず文字列として表示する場合は、先頭にシングルクォートを加えます。例えばセルの値を `'=SUM(A1:A3)` にすると、画面には `=SUM(A1:A3)` と表示されます。

## JSONへの保存

セルの `value` には、計算結果ではなく入力した式の文字列を保持します。`serializeWorkbook` / `parseWorkbook` でJSONを保存・復元でき、コンポーネントは復元した式を再計算して表示します。計算結果をブックの別フィールドに二重保存する必要はありません。

```ts
import {
  calculateWorkbook, parseWorkbook, serializeWorkbook,
  type SpreadsheetWorkbook,
} from "@likex/spreadsheet";

const workbook: SpreadsheetWorkbook = {
  schemaVersion: 1,
  sheets: [{
    id: "budget", name: "予算", rowCount: 300, columnCount: 26,
    cells: {
      A1: { value: "1200" },
      A2: { value: "300" },
      A3: { value: "=SUM(A1:A2)" },
    },
  }],
};

const json = serializeWorkbook(workbook);
const restored = parseWorkbook(json);
restored.sheets[0].cells.A3.value; // "=SUM(A1:A2)"
const values = calculateWorkbook(restored);
values.budget.A3; // 1500
```

`calculateWorkbook` は `sheetId` → A1アドレス → 計算結果のオブジェクトを返します。式の文字列を持つ元のブックは変更しません。保存コールバックへの接続例は [公開API](./api.md#保存)、画像等も含む形式は [JSON保存](./insertions-and-json.md) を参照してください。

## 機能設定と対応範囲

`features={{ formulas: false }}` で数式入力と関数の入力補助を無効化できます。初期ブックに含まれる数式の計算結果は引き続き表示します。`readOnly` または `onSave` の省略でも編集できなくなります。

Excelの関数・型変換・表示規則の完全互換ではありません。動的配列、外部ブック参照、利用側による独自関数の登録は提供していません。検索の返却範囲や日付方式など、上記の対応範囲で使用してください。数値はJavaScriptの浮動小数点数で計算するため、小数の演算には丸め誤差が生じることがあります。

未対応の関数は `#NAME?`、不正な値は `#VALUE!`、ゼロ除算は `#DIV/0!`、不正な参照は `#REF!`、循環参照は `#CYCLE!` として表示します。式の長さ・参照の深さ・範囲の大きさ・計算量等には上限があり、超過は `#LIMIT!` になります。公開定数 `SPREADSHEET_LIMITS` で上限を確認できます。JavaScriptの `eval` / `Function` は使用しません。

`IFERROR` が代替値に置き換えるのは `#REF!` / `#DIV/0!` / `#VALUE!` / `#NAME?` / `#NUM!` / `#N/A` / `#NULL!` です。安全のための `#LIMIT!`、循環参照の `#CYCLE!`、構文等の `#ERROR!` は置き換えません。式全体が構文として読み取れない場合も、分岐に入る前にエラーになります。
