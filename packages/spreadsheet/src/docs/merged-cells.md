# セルの結合・解除

[利用ガイドへ戻る](./README.md)

連続した長方形の範囲を選び、「ホーム」の「セルを結合」を押します。横方向・縦方向・複数行列の結合に対応します。結合セルを選んで「結合を解除」を押すと、元のセル配置に戻ります。離れた複数範囲をまとめて結合する操作はできません。

## 値と操作

- 値・数式・コメントは左上のセルに保持します。他のセルにも内容がある場合は、削除して結合してよいかを確認します。キャンセル・Escape・暗い背景のクリックでは結合しません。
- 結合解除だけでは削除した内容は復元されません。Undoが有効なら、結合操作を元に戻すことで復元できます。結合で隠れるセルの書式は保持します。
- 結合セルのクリックは全体を選択します。範囲選択が結合セルの一部に触れる場合も、その結合全体を含めます。矢印・Tab・Enterでは結合の外へ移動します。
- 編集は左上のセルへ反映します。数式が左上以外のセルを参照した場合は空セルとして扱い、範囲の合計では左上の値を1回だけ数えます。
- 結合と解除は下書きの変更です。`onChange`、Undo／Redo、`onSave` の対象になります。

行列を結合の前に挿入すると位置が移動し、結合の内部への挿入では範囲が広がります。行列の削除では範囲が縮まり、1セルになった場合は結合がなくなります。左上のセルがある行／列そのものを削除した場合、その値とコメントも削除されます。

## コピー・貼り付け

| 操作 | 動作 |
| --- | --- |
| 同じコンポーネント内で結合を含む範囲をコピー | 結合・値・数式・書式・コメントを保持して貼り付け |
| 結合全体を切り取り | 同じシート／別シートへ結合と内容を移動 |
| 通常の1セルをコピーし、結合セルへ貼り付け | 結合を維持して左上の内容を更新 |
| 外部の1セル値を結合セルへ貼り付け | 結合を維持して左上の値を更新 |
| 外部の複数セルを結合に重ねて貼り付け | 結合解除を案内し、貼り付け全体を中止 |
| 結合の一部だけに重なる切り取り元／貼り付け先 | 全体を中止。隠れたセルへの書き込みはしない |

内部コピーでは、貼り付け先の矩形に完全に含まれる既存の結合を、コピー元の結合配置に置き換えます。`comments: false` で非表示になっているコメントを、新しい結合が隠してしまう場合は、コメントを削除せず貼り付けを中止します。

外部へ渡すTSVには結合情報がありません。別コンポーネントへのコピーや、内部のコピー情報を失った場合もTSVの値として扱います。

## JSONと公開型

シートの `merges` に0始まり・両端を含む矩形を保存します。旧形式のブックは変更せず読み込めます。

```ts
import { mergeCells, unmergeCells, type SpreadsheetWorkbook, type SpreadsheetMergedRange } from "@likex/spreadsheet";

const range: SpreadsheetMergedRange = { top: 0, left: 0, bottom: 1, right: 2 }; // A1:C2
const workbook: SpreadsheetWorkbook = {
  schemaVersion: 1,
  sheets: [{
    id: "main", name: "見積", rowCount: 100, columnCount: 26,
    cells: { A1: { value: "見積書", format: { align: "center", bold: true } } },
    merges: [range],
  }],
};

const separated = unmergeCells(workbook, "main", range);
const merged = mergeCells(separated, "main", range);
// 左上以外の値・コメントを捨てる場合は、利用側で確認した後に明示指定します。
// mergeCells(separated, "main", range, { discardValues: true });
```

`mergeCells` / `unmergeCells` は元のブックを書き換えず、新しいブックを返します。内容を捨てる必要があるかは `mergedContentWouldBeDiscarded(sheet, range)` で確認できます。`getMergedRange`、`mergedCellPosition`、`expandRangeForMerges` は、結合の取得・編集先・結合を含む選択範囲の計算に使えます。

`normalizeWorkbook` / `parseWorkbook` は範囲外・重複・不正な矩形と、結合で隠れるセルの非空の値・コメントを拒否します。JSONには左上だけに内容を入れてください。`setCellValue` は結合内のアドレスを左上へ解決しますが、複数値を一度に書く `setCellValues` は隠れる位置への非空の書き込みを拒否します。

`onSelectionChange` の `ranges` は選択した幾何学的な範囲を表します。`focus` は編集先となる結合の左上へ解決されるため、最後の範囲の右下座標とは一致しない場合があります。全体の範囲は `ranges`、編集中のセルは `focus` を使ってください。

## 機能設定と上限

`features={{ mergeCells: false }}` で結合・解除の操作を隠せます。既定はONです。保存済みの結合は引き続き表示し、JSONにも保持します。コピー・貼り付けによる結合配置の変更もOFFの対象ですが、左上セルの値を更新する通常の編集は利用できます。`formatting: false` とは独立した設定です。読み取り専用では結合・解除もできません。

画面から一度に結合できる範囲は10,000セルまで、保存できる結合はブック全体で1,000範囲までです。公開モデル関数は空セルの全展開をせず処理するため、シート内のより大きい矩形も保持できます。
