# 画面の編集機能

付箋・テキスト・四角・楕円・画像を配置できます。オブジェクトはドラッグで移動し、選択すると四隅のハンドルでサイズを変更できます。画像は縦横比を保って変更します。右のプロパティでテキスト、色、文字サイズ、幅・高さを編集できます。

Shiftを押しながらクリックすると複数選択になります。複数オブジェクトの移動・削除・左揃え、最前面・最背面への移動に対応しています。配列の後ろにあるオブジェクトほど前面に表示されます。

右クリックすると対象に応じた操作メニューを開きます。オブジェクトではテキスト（画像は代替テキスト）の編集、複製、最前面・最背面、削除を選べます。選択済みのオブジェクトを右クリックすると複数選択を保ち、複製・重なり順・削除をまとめて実行します。別のオブジェクトを右クリックすると、そのオブジェクトだけが対象になります。複数選択の「テキストを編集」は右クリックした1件を選び直してプロパティへ移ります。

余白のメニューにはクリック位置への付箋・テキスト・図形・画像追加、Undo/Redo、すべて選択、全体表示があります。キーボードのメニューキーでも、フォーカス中のキャンバスの選択対象から開けます。入力欄ではブラウザーの文字編集メニューを維持し、Shiftを押しながら右クリックすると通常のブラウザーメニューを開きます。無効な`features`の操作は非表示、読み取り専用・処理中の編集操作は無効になり、実行時にも共通コントローラーが編集許可を確認します。メニューを開いた後に文書が更新された場合は古い操作を適用しません。

複製は元の属性を持つ新しいIDの`element.add`をまとめて実行し、位置を右下へ24ずらします。その他も既存の`elements.order`・`elements.align`・`element.remove`を使うため、API/CLIと同じ保存内容になり、1回のUndoで戻せます。

空白または手のツールでキャンバスをドラッグして移動します。下部のボタンで拡大縮小・全体表示を切り替えます。表示倍率と表示位置は保存対象に含めません。

オブジェクトの移動中は、実際の寸法を保ったまま半透明に表示します。ポインターをキャンバスの端や外へ動かすと、その方向へ表示が自動で移動します。ドロップ時に共通コマンドで位置を確定するため、Undoで移動前へ戻せます。Escapeでドラッグを取り消せます。途中でデータや編集可否が変わった場合も、移動を確定せずに終了します。

| `features`のキー | 対象 |
| --- | --- |
| `elements` | オブジェクトの追加・更新・削除・重なり順 |
| `images` | 画像の追加・画像データの変更 |
| `move` | 移動・整列 |
| `resize` | サイズ変更 |
| `formatting` | 色・文字サイズ |
| `import` / `export` | JSONの読み込み、JSON・SVGの書き出し |
| `history` | Undo/Redo |

Ctrl/Cmd+Sで保存、Ctrl/Cmd+ZでUndo、Ctrl/Cmd+Shift+ZまたはCtrl+YでRedo、Deleteで削除、Escapeで選択解除できます。入力欄では文字の編集を優先します。

画像は8 MiB以下のPNG・JPEGをJSONに埋め込みます。画像のアップロード準備中に対象が変わった場合や、読み取り専用になった場合は結果を適用しません。外部画像のURLは取得しません。

## 対応範囲

付箋や資料を自由に配置するボードです。手書きペン、コネクター、グループ化、リアルタイム共同編集はこの初版に含みません。接続関係を扱う図にはLikeDiagramを使えます。SVGは静的な表示・配布用で、再編集にはJSONを保存してください。

`colorMode`はヘッダーや操作パネルの配色を切り替えます。文書のキャンバスはSVG出力と同じ白地を維持し、保存した文字色・画像・塗り色をモード変更で反転させません。
