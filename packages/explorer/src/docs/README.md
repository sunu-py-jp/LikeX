# Explorerドキュメント

[Explorerの概要](../README.md)

最初は[導入](./getting-started.md)と[保存の契約](./saving.md)を確認し、必要な機能のガイドへ進んでください。以下は現在の公開APIの説明です。外部ストレージ・Azureの設計例や未実装の構想は末尾で分けています。

各例の `@/components/explorer` はコピー配置先の公開入口です。パッケージ導入では `@likex/explorer` に読み替え、CSSを1回importします。`save`・`savedEntries` などを使う抜粋は、親が用意する保存関数・一覧と組み合わせてください。
