# スライドとオブジェクトの編集

画面の左にスライド一覧、中央にキャンバス、右に選択したオブジェクトの設定を表示します。リボンはホーム・挿入などのタブ内で、クリップボード、スライド、配置、書式といったグループに分かれています。

## スライド

スライドの追加・複製・削除と、左の一覧をドラッグしての並べ替えができます。背景色はカラーピッカーで設定します。発表用のノートもJSONに保存します。最低1枚のスライドを残すため、最後の1枚は削除できません。

## テキスト・図形・画像

| 要素 | 編集できる内容 |
| --- | --- |
| テキスト | 内容、フォント、サイズ、太字・斜体、文字色、水平・垂直配置、背景色 |
| 図形 | 長方形、角丸長方形、楕円、三角形、ひし形、矢印、線。塗り・枠線・文字 |
| 画像 | PNG / JPEG / GIF / WebP、位置・寸法・回転・代替テキスト |

ドラッグで移動し、四隅のハンドルで大きさを変えます。回転ハンドルで回転します。Shiftを押しながらクリックすると複数の要素を選択できます。前面・背面への並べ替え、複製、削除もできます。画像はJSON内のdata URLとして保持し、表示時に外部URLへ取りに行きません。

文字はダブルクリックで編集できます。オブジェクトの編集中に使うコピー・貼り付けと、テキスト編集中の通常の文字操作を分けています。

## 履歴と発表

Undo / Redoは保存後も保持します。発表表示では現在の資料を大きく表示し、矢印キーで前後のスライドへ移動、Escapeで編集画面へ戻ります。

| キー | 操作 |
| --- | --- |
| Ctrl / Cmd + Z | 元に戻す |
| Ctrl / Cmd + Shift + Z、Ctrl + Y | やり直す |
| Ctrl / Cmd + C、V | 選択した要素のコピー・貼り付け |
| Delete / Backspace | 選択した要素を削除 |

ブラウザーの予約キーやIME編集中は、ブラウザーと文字入力を優先します。ズームは編集画面の見え方だけを変え、保存されるスライド寸法には影響しません。
