# スライドとオブジェクトの編集

画面の左にスライド一覧、中央にキャンバスを表示します。右側の書式設定パネルは初期状態では閉じています。表示タブの「書式設定」、またはオブジェクトの右クリックメニューの「書式設定」から開けます。リボンはホーム・挿入などのタブ内で、クリップボード、スライド、配置、書式といったグループに分かれています。

## スライド

スライドの追加・複製・削除と、左の一覧をドラッグしての並べ替えができます。背景色はカラーピッカーで設定します。発表用のノートもJSONに保存します。最低1枚のスライドを残すため、最後の1枚は削除できません。

一覧では Ctrl / Cmd を押しながらクリックすると選択を追加・解除し、Shiftクリックで起点からの連続したページを選択します。選択したサムネイルにフォーカスがある状態の Delete / Backspace は、選択ページをまとめて削除します。各ページの削除ボタンはその1枚だけを削除します。複数ページの削除も1回のUndoで内容と選択を戻せます。全ページを選択した場合は削除せず、最低1枚を残す案内を表示します。

一覧の並べ替え中は小型の半透明プレビューと挿入位置の線を表示します。ポインターを一覧の上下端や外へ動かすと、自動でスクロールします。一覧の表示領域内でドロップすると `slide.move` で順番を確定します。一覧の外で離した場合は並べ替えを取り消します。

## テキスト・図形・画像

| 要素 | 編集できる内容 |
| --- | --- |
| テキスト | 内容、フォント、サイズ、太字・斜体、文字色、水平・垂直配置、背景色 |
| 図形 | 長方形、角丸長方形、楕円、三角形、ひし形、右・左の太いブロック矢印、線。塗り・枠線・文字 |
| 画像 | PNG / JPEG / GIF / WebP、位置・寸法・回転・代替テキスト |

ドラッグで移動し、通常の図形は四隅のハンドルで大きさを変え、回転ハンドルで回転します。線は始点・終点の2ハンドルで変更し、矩形用の変形・回転ハンドルは表示しません。端点をドラッグして図形へ近づくと最寄りの図形だけ8接続点が現れ、近づけると吸着して以後の移動・変形・回転に追従します。点から離して動かすと接続を解除します。線のメニューは直線・右向き矢印線・左向き矢印線・双方向矢印線を分け、書式パネルで始点と終点それぞれの矢印を変更できます。図形の太いブロック矢印とは別の操作です。線本体は線の近くだけクリックでき、斜め線の外接矩形内の余白は選択を妨げません。Shift / Ctrl / Cmd を押しながらクリックすると複数の要素を選択できます。キャンバスや周囲の余白からドラッグすると選択枠を表示し、回転後の外接矩形が枠内に完全に収まる要素だけを選択します。線は両端が選択枠に収まる場合だけ選びます。一部だけ重なる要素は選びません。Shift / Ctrl / Cmd を押した範囲選択では、囲んだ要素の選択を切り替えます。読み取り専用や書式機能が無効でも選択できます。

キャンバスにフォーカスがある状態の Delete / Backspace は、選択した要素をまとめて削除します。ロックされた要素を含む場合は一括操作全体を拒否します。前面・背面への並べ替え、複製もできます。画像はJSON内のdata URLとして保持し、表示時に外部URLへ取りに行きません。

移動中のオブジェクトは実寸のまま半透明に表示します。拡大したキャンバスの端や外へドラッグすると表示領域を自動でスクロールします。図形のサイズ変更・回転、画像の縦横比の扱いは通常の操作と同じです。

一覧とキャンバスのドラッグはEscapeで取り消せます。途中でデータ・表示中のスライド・編集可否が変わった場合は、古い位置や順序を確定しません。親の編集許可を待つ間に資料が変更された場合も、待機中の操作を適用しません。

文字はダブルクリックで編集できます。オブジェクトの編集中に使うコピー・貼り付けと、テキスト編集中の通常の文字操作を分けています。

## 右クリックメニュー

オブジェクトを右クリックすると、その対象のテキスト編集、コピー・切り取り・複製、最前面・最背面への移動、ロック・解除、削除、書式設定を選べます。選択済みのオブジェクトを右クリックした場合は複数選択を保ち、未選択のオブジェクトを右クリックした場合はその1個を選択します。「書式設定」はこの選択を対象に既存のパネルを開きます。ロック中はコピー、ロック解除、書式設定の表示を利用できます。読み取り専用でも書式設定を表示できますが、編集はできません。パネルを開閉しても未保存状態やUndo履歴は変わりません。

キャンバスの余白からテキスト・四角形・画像・スライドを追加でき、コピー済みのオブジェクトがあれば貼り付けもできます。テキストと四角形は右クリック位置を基準に追加します。スライド一覧では、右クリックしたスライドの後への追加、複製、前後への移動、削除を選べます。

画像の追加対象はファイル選択を開く時点で固定します。ファイル選択・画像の読み込み・編集許可の確認中に資料や表示中のスライドが変わった場合は追加を取り消します。リボンからの画像追加も同じ扱いです。

メニューは既存の `element.add/update/duplicate/order/delete`、`slide.add/duplicate/move/delete` を使うため、公開APIと同じ編集許可・履歴・通知の経路を通ります。機能フラグが無効な項目や、読み取り専用での編集項目は表示しません。処理中や編集許可の確認中は編集項目を無効にします。資料または編集可否が変わるとメニューを閉じ、許可待ちの間に資料が更新されても古い対象へ操作を適用しません。文字入力欄ではブラウザーの右クリックメニューを使います。保存モデルとPPTX変換の対応範囲は変わりません。

## 履歴と発表

Undo / Redoは保存後も保持します。発表表示では現在の資料を大きく表示し、矢印キーで前後のスライドへ移動、Escapeで編集画面へ戻ります。

| キー | 操作 |
| --- | --- |
| Ctrl / Cmd + Z | 元に戻す |
| Ctrl / Cmd + Shift + Z、Ctrl + Y | やり直す |
| Ctrl / Cmd + C、V | 選択した要素のコピー・貼り付け |
| Ctrl / Cmd + A | フォーカス中の一覧で全ページ、キャンバスで全要素を選択 |
| Delete / Backspace | フォーカス中の一覧で選択ページ、キャンバスで選択要素を削除 |

ブラウザーの予約キーやIME編集中は、ブラウザーと文字入力を優先します。ズームは編集画面の見え方だけを変え、保存されるスライド寸法には影響しません。

ノート・プロパティの入力欄や、一覧・キャンバス以外のボタンにフォーカスがある場合、Deleteでページや要素を削除しません。編集許可の確認中に選択や資料が変わると、選択削除を取り消します。

Shiftを押しながら右クリックすると、通常のブラウザーメニューを使えます。
