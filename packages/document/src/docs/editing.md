# 文書を編集する

本文入力とリボンの操作は共通の文書コマンドを通り、Undo／Redoで戻せます。保存前の変更は下書きです。利用側の保存先へは `onSave` を通して反映します。

## 文章と書式

通常の段落、見出しレベル1〜6、改行、箇条書き、番号付きリストを扱います。文字には太字・斜体・下線・取り消し線・フォント・ポイント数・文字色・背景色・リンク、段落には左・中央・右・両端揃えを設定できます。

文書内の位置はProseMirrorの位置です。最初の段落の先頭文字は `1` で、ブロックの境界も位置に数えます。本文の文字インデックスや画面の座標を直接渡さず、APIの `getBlocks` / `getBlock` で現在の範囲を取得してください。複数操作の後続コマンドには、その時点の文書の位置を使います。

## 表・画像・改ページ

表は行・列数と見出し行の有無を指定して追加し、セル内で文章を編集します。モデルはセルの列結合・行結合・幅・背景色を保持します。Wordからの変換時の扱いは [DOCX入出力](docx.md) にあります。

画像は埋め込んだPNG／JPEGを保存します。画像の寸法はピクセル、フォントサイズはポイント、用紙・余白はミリメートルです。画像説明は `alt` で保持します。外部URLから画像を自動取得する処理はありません。

`pageBreak.insert` は明示的な改ページを追加します。用紙サイズ・余白とブラウザーのフォント描画は、Wordと完全に同じページ分割になるとは限りません。

## 図形

挿入タブの「図形を挿入」から、四角形・円・カギ矢印・Uターン矢印・方向矢印・フローチャートなど39種類のOfficeプリセットを追加できます。選択するとリボンの「図形の書式」でテキスト・幅と高さ・回転・反転・塗りつぶし・線・文字色とサイズを変更できます。図形は本文の流れに置く編集可能なブロックで、画像には変換しません。

図形の移動は本文中でのドラッグ、削除は選択後のDeleteまたは右クリック、複製は右クリックから行います。`shape.insert` / `shape.update` / `block.delete` と同じ編集許可・履歴の経路を使います。`features.text: false` は図形内の文字編集や文字入り図形の新規追加も無効にします。`features.formatting: false` は図形の寸法・色・回転などの変更と独自書式付きの追加を無効にします（既定の書式での追加は可能）。`features.shapes: false` では図形の追加・変更・削除・移動を無効にし、文書全体の明示的なインポートは既存の `import` 契約に従います。

## 描画キャンバスと接続線

図形をつなぐ場合は、挿入タブの「描画キャンバス」を使います。本文中のキャンバスを選び「キャンバスを編集」を開くと、39種類の図形を追加し、文字や書式を設定してドラッグで配置できます。キャンバス内の図形を接続元・接続先として選び、上・下・左・右・四隅の接続点を指定して「直交コネクタを追加」を押します。

線は自動で水平・垂直の区間を組み合わせます。図形の移動・拡縮・回転に端点と経路が追従し、線の書式から直線への変更や始点・終点の矢印設定もできます。図形や線を選択してDelete／Backspace、または「選択を削除」で削除します。接続先の図形を削除した線は、その時点の端点位置を保って接続だけ解除します。キャンバスでの変更は文書へ即時反映し、削除・移動・文字変更は共通のUndo／Redoで戻せます。

接続は同じキャンバス内で行います。通常の本文中の図形ブロックや別キャンバスへは接続しません。直交経路は接続元・接続先の輪郭から計算し、第三の図形を自動で避ける機能は含みません。編集中のドラッグはプレビューで、終了時に1回の編集として反映します。文書が途中で更新された場合はそのドラッグを中止します。

`features.shapes` はキャンバスと内部図形・接続線の編集、`features.text` は図形の文字、`features.formatting` は位置・寸法・色・線の書式を制御します。接続線は同じ編集許可・読み取り専用・履歴の経路を通ります。

## 本文・画像をドラッグで移動する

選択した本文や画像をドラッグすると、小型の半透明プレビューと挿入位置の目印を表示します。本文の表示領域の端や外へポインターを動かすと、自動でスクロールします。画像をドラッグしても保存する寸法は変わりません。

ドロップは本文編集と同じ `transaction.apply` の経路で処理し、編集許可・機能設定・Undo/Redoを適用します。Escapeで取り消せます。途中で文書や編集可否が変わった場合は古いドラッグを中止します。

## 右クリック

画像では選択・複製・縦横比を保つ縮小（80%）と拡大（125%）・削除、表の枠やセルの余白では表全体の選択・削除ができます。文書の余白では本文全体のコピー・選択とUndo/Redoを使えます。表内も含め、本文の通常の右クリックはブラウザーのメニューを使い、スペルチェックや標準のコピー・貼り付けを維持します。

余白にフォーカスするか、画像・表全体を選択した状態でShift+F10またはメニューキーを押しても開けます。無効な機能は表示せず、読み取り専用では変更操作を表示しません。文書・選択・編集可否が変わった場合は古いメニューを閉じ、編集許可を待つ間の変更も確認してから反映します。コピーにはブラウザーのクリップボード権限が必要です。

画像の複製は `image.insert`、サイズ変更は `image.update`、画像・表の削除は `block.delete` と同じ操作です。表の行列変更・複製の専用メニューはありません。保存構造とDOCXの変換範囲は変わりません。

## 機能を無効にする

```tsx
<LikeDocument initialDocument={document} onSave={saveDocument}
  features={{ images: false, tables: false, import: false }}
  style={{ height: 720 }} />
```

`DocumentFeatures` は `text`、`formatting`、`lists`、`tables`、`images`、`shapes`、`pageLayout`、`import`、`export`、`history` を指定します。省略した機能は有効です。GUIと表示中コンポーネントのref経由の操作は、同じ機能設定・読み取り専用・編集許可の処理を使います。純粋なモデルAPIにはUIの機能設定や認証状態を持ち込みません。
