# 画面の編集機能

処理（四角）、条件（ひし形）、開始・終了（楕円）を配置できます。「接続」を押し、始点と終点のノードを順に選ぶと矢印で結ばれます。接続線を選ぶとラベルと色を編集できます。

ノードはドラッグで移動し、選択したノードの四隅でサイズを変更できます。Shiftを押しながらクリックすると複数選択になり、まとめて移動・削除・左揃えできます。テキストや色、幅・高さは右のプロパティで変更します。テキスト編集欄はノードのダブルクリックでもフォーカスできます。

右クリックメニューはノード・接続線・余白に対応します。ノードではテキスト編集、複製、最前面・最背面、ここから接続、削除、接続線ではラベル編集、複製、最前面・最背面、削除を選べます。選択済みの対象を右クリックすると複数選択を保ち、別の対象では1件へ選び直します。「編集」は右クリックした1件のプロパティにフォーカスします。

複製は新しいIDの`node.add`・`edge.add`を1つのバッチで実行します。選んだノードは右下へ24ずれ、選択ノード同士の接続線も複製して新しいIDへ結び直します。明示的に選択した接続線も複製し、選択されていない端点は元のノードに接続します。重なり順は`nodes.order`・`edges.order`（`position: "front" | "back"`）を使い、それぞれの配列内の順序を変更します。接続線は常にノードより背面に描画し、JSONとSVGでも順序を保ちます。

余白ではクリック位置へのノード追加、Undo/Redo、すべて選択、全体表示ができます。キーボードのメニューキーでもフォーカス中のキャンバスから開けます。入力欄ではブラウザーの文字編集メニューを維持し、Shiftを押しながら右クリックすると通常のブラウザーメニューを開きます。無効な`features`の操作は非表示、読み取り専用・処理中の編集操作は無効になり、実行時にも既存コントローラーが編集許可を確認します。文書更新後に古いメニューの操作は適用しません。複製・削除などの一括操作も1回のUndoで戻せます。

空白または手のツールでキャンバスをドラッグして移動します。下部のボタンで拡大縮小・全体表示を切り替えます。キャンバスの移動や表示倍率は保存対象に含めません。

ノードの移動中は、実際の寸法を保ったまま半透明に表示します。ポインターをキャンバスの端や外へ動かすと、その方向へ表示が自動で移動します。ドロップ時に共通コマンドで位置を確定するため、Undoで移動前へ戻せます。Escapeでドラッグを取り消せます。途中でデータや編集可否が変わった場合も、移動を確定せずに終了します。

| `features`のキー | 対象 |
| --- | --- |
| `nodes` | ノード追加・編集・削除・重なり順 |
| `edges` | 接続線の追加・編集・削除・重なり順。ノード削除は接続線も消すためこの機能も必要 |
| `move` | 移動・整列 |
| `resize` | サイズ変更 |
| `formatting` | 色・ノードの種類の変更 |
| `import` / `export` | JSONの読み込み、JSON・SVGの書き出し |
| `history` | Undo/Redo |

Ctrl/Cmd+Sで保存、Ctrl/Cmd+ZでUndo、Ctrl/Cmd+Shift+ZまたはCtrl+YでRedo、Deleteで選択を削除、Escapeで接続・選択を解除します。入力欄にフォーカスがある間は、文字の編集を優先します。

## 対応範囲

業務フローや構成図を描くためのエディターです。矢印はノードの境界に追従する直線です。自動レイアウト、直角の経路探索、BPMN互換、条件の評価やフローの実行は含みません。SVGは表示・配布用であり、再編集にはJSONを保存してください。画面とSVGのフォント環境によって文字の見え方は異なります。

`colorMode`はヘッダーや操作パネルの配色を切り替えます。文書のキャンバスはSVG出力と同じ白地を維持し、保存した文字色・画像・塗り色をモード変更で反転させません。
