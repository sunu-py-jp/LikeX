# 追加モジュールとチャット分離の実装・検証記録

2026年9月22日の初期実装記録です。Board、Diagram、Calendar、Whiteboard、Chat（現在のAIChat）、DataView、Formを並行して実装し、共通基盤・フォーム・各公開入口を担当者以外もレビューしました。外部サービスの完全な再現ではなく、以下の機能を備えた初期実装です。

| モジュール | 実装範囲 | 今回含めないもの |
| --- | --- | --- |
| Board | 列・カード・ラベル・担当者、ドラッグ移動、検索 | サーバー上のタスク管理・共同編集 |
| Diagram | ノード・接続線、移動・変形・整列、ズーム、SVG出力 | 外部作図サービスの専用形式 |
| Calendar | 月・週・日、予定の追加・変更・移動、タイムゾーン | 繰り返し予定、ICS、外部カレンダー同期 |
| Whiteboard | 付箋・テキスト・図形・画像、移動・変形・重なり順、SVG出力 | フリーハンド、接続線、リアルタイム共同編集 |
| AIChat（旧Chat） | 会話・メッセージ、親が返すストリーミング応答、中止・再生成、添付情報 | AIプロバイダー接続・ファイル保存の内蔵実装 |
| DataView | 型付きレコード、セル編集、フィールド編集、検索・絞り込み・グループ化、CSV | DB接続・大量データのサーバークエリー |
| Form | 設計・回答モード、7種類の項目、入力検証、条件表示、非同期送信 | 回答DB・認証・配信サービス |

各モジュールは保存用JSON、画面なしのモデルAPI、LLM向けスキル・CLIを持ちます。GUIの編集は共通のモデル操作を使い、保存・編集許可・機能設定・履歴の制御をcoreのコントローラーへ集約しています。モデルAPIの認証・競合制御は利用側の責務です。

## 残る実機確認

内蔵ブラウザでFormの日付入力のカレンダーボタンを開いた際、タブがクラッシュしました。ネイティブの日付ピッカーを利用しており、ブラウザ側を含む原因の切り分けは未完了です。日付値・必須検証のモデルテストは通っていますが、このピッカーの操作と通常Chromeでの確認は完了扱いにしていません。デモは新しいタブで復旧しています。

デモの保存・回答送信・AIChat応答はメモリ上のサンプル処理です。本番の接続方法と機能の詳細は各モジュールのガイド、[API Docs](APIDocs/index.html)を参照してください。


## LikeAIChatへの分離と人同士のLikeChat

AI会話を `@likex/aichat` / `LikeAIChat` / `/aichat` へ移し、`@likex/chat` / `LikeChat` / `/chat` は人同士のDM・グループ・スペース用に分離しました。既存のAIストリーミング、再試行・中止、添付・参照・ツール情報、モデルAPI・セッション・履歴はAIChatへ引き継ぎます。

保存形式はAIChatが `likex.aichat` / version 1、人同士のChatが `likex.chat` / version 2です。旧AIの `likex.chat` / version 1をAIChatへ読み込む際は全構造を検証し、人物向けのChat構造や不正なID・返信参照などは受け付けません。API名とファイルの移行は [AIChatのガイド](../packages/aichat/src/docs/native-files.md#旧likechatからの移行)を参照してください。

分離後のAIChatのモデル・セッション・UIテスト28件、型チェック、対象ファイルのLintが成功しました。旧ファイルの移行、入力を変更しないこと、人同士の構造の拒否、応答のキャンセルと遅延結果の抑止を含みます。上の初期実装の件数は当時の結果であり、人同士の新しいChatの検証件数を含みません。
